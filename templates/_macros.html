{# Jinja macros for reusable form components. unit_combobox(field, css_class) Renders a WTForms StringField as a custom combobox: the text input looks like every other field, but tapping it (or its chevron) drops down a styled menu of common units anchored directly below the input. Typing filters the visible options; arrow keys navigate; Enter picks the highlighted option; Escape closes. The input is still free-text, so the user can type a unit not in the list and submit it normally. The behavior lives in base.html's
